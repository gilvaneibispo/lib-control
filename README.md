# lib-control
Projeto final da disciplina Plataforma de Desenvolvimento em Software Livre e Servidores Web da pós-graduação em Desenvolvimento Web (IFSULDEMINAS). Sistema de gestão de biblioteca com catálogo público, reservas, empréstimos, devoluções, cadastro via ISBN e OCR. Stack: React, TypeScript, Bootstrap 5, Laravel, Python, Docker Compose e Nginx.
